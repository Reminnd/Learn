- `0`：未接触
- `1`：需要大量引导

## 更新规则

1. 只有练习、Q&A、用户代码、调试或设计题构成证据。
2. 一次表现好不必直接跨多级；看是否能重复独立完成。
3. 长时间未使用不自动降级，但复习时应重新验证。
4. 同一能力在“看懂”高，不代表“独立实现/调试”也高。
5. 当某知识点的“独立实现”达到 3，或章节整体已 mastered，可主动提示：**可以尝试面试官模式做无提示检验**。

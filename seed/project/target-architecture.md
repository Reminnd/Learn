# Target Architecture（目标架构）

当前状态：`TBD`。

用户尚未选择真正的长期项目，因此现在不预设目标架构。

在 Project Track 激活后：

1. 先定义业务目标与核心用户场景。
2. 再确定系统边界与非目标。
3. 按已学习能力设计第一版最小架构。
4. 后续每引入 Context / RAG / Memory / Multi-Agent / Security / Observability 等模块时，通过实际需求决定是否集成。
5. 关键选择先解析 manifest 的 `adr.root`，再写入 ADR。

不要先画一个“大而全”的企业架构再硬套项目。

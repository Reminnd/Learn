# Bug Book（错题本 / 调试本）

> 只记录可复用的错误模式，不记录聊天流水账。默认按需读取当前主题或最近条目，不要每次全部加载。

## 状态

- `open`：仍容易犯错，需要复习
- `improving`：已纠正，但还需要再次验证
- `resolved`：已通过后续练习 / Q&A 验证
